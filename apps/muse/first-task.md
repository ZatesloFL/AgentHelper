# Guided Flow: First Task Template

**App ID**: `first-task`
**Title**: Define Your First Task
**Estimated Time**: 5 minutes
**Goal**: Choose one small, low-stakes, repeatable task and formulate it into a bounded goal template.

## Steps
1. **Identify a Low-Stakes Candidate**: Choose a narrow, low-risk task (such as bookmark organizing or summarizing public notes) carrying zero financial or communication risk.
   - *Coach Question*: "What is one small, repetitive task you do often that carries zero financial or privacy risk if something went wrong?"
2. **Draft the Goal Contract**: Co-create the instructions using the structured contract: Goal, Allowed Actions, Forbidden Boundaries, and Sign-Off Triggers.
   - *Coach Question*: "In your own words, what should Muse do, what is it strictly forbidden from doing, and when must it ask for your approval before proceeding?"
3. **Review Guardrails**: Review each line of the prompt together to verify least access and ensure zero automated write actions occur without your review.
   - *Coach Question*: "Looking over this instruction draft together, does anything feel too open-ended or risky? What boundaries should we tighten?"
4. **Dry Run & Supervised Execution**: Run the task once with close supervision, observing Muse's step-by-step reasoning and adjusting boundaries.
   - *Coach Question*: "Let's run this prompt once together. Watch how Muse responds and tell me if its actions match exactly what you expected."

## Completion
Conclude with a copyable summary of the template and save the goal to session notes via `save_session_note`.
